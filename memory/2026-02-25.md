### Created

  - https://github.com/openclaw/openclaw/issues/26222

### Technical Findings
- `extensions/feishu/src/docx.ts` uses action-based dispatch via `registerFeishuDocTools()`
- Tools registered via `api.registerTool()` with switch statement for actions
- Block type 31 = Table, Block type 32 = TableCell
- Table blocks currently in `UNSUPPORTED_CREATE_TYPES` set
- Schema defined in `./doc-schema.js`

### Implementation Approach (Method 2)
1. Create empty table with POST to `client.docx.documentBlockChildren.create()` (block_type 31)
2. Response contains `cell_id` list for all cells
3. Fill each cell with content via separate POST calls (block_type 2 text blocks)
